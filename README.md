# Site institucional

Este site foi criado para funcionar como cartão de visita digital e apresentação institucional para serviços de sistemas web personalizados.

## Arquivos

- `index.html`: estrutura da página
- `styles.css`: visual e responsividade
- `script.js`: textos, cases, serviços e contatos editáveis

## Como personalizar

Edite o objeto `siteConfig` em `script.js`.

Campos que você provavelmente vai querer trocar primeiro:

- `brandName`
- `brandTag`
- `contact.channels`
- `cases`
- `about.badges`

## Publicar rápido

Você pode publicar esta página em qualquer hospedagem estática, como:

- GitHub Pages
- Netlify
- Vercel

Como é um site estático, basta subir os três arquivos principais.
